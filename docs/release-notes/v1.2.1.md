## Scaling filter

With **Fit the image into the canvas size** on, the source scales the picture
itself and the scene item stays at 1:1. The item's own scale filter then has
nothing left to do, so an upscaled pixel-art game went through the plain sampler
and came out smeared.

A filter choice now sits next to that checkbox:

| Filter | Use it for |
| --- | --- |
| Bilinear | the default, fine for most things |
| Point | old games and pixel art, keeps the pixels hard |
| Bicubic | shrinking a capture larger than the canvas |
| Lanczos | the same, sharper and slower |

These are the scaling effects OBS ships for scene items, so the result matches
what OBS itself would produce. Below half size the source switches to the
low-resolution bilinear effect, where the multi-tap filters stop helping.

The filter applies while the source does the scaling. When the address bar blur
is covering something, that frame goes through the blur effect instead. That
combination only happens on a browser, which has no use for point filtering.

## Settings window no longer squeezes its own fields

The rule editor's rows could be clipped to a few pixels high. The lower half of
the window had a fixed minimum height, and the page content grew past it: 1.1.0
added the fit checkbox, 1.2.0 the scaling filter. The form compressed its rows
instead of the window refusing to shrink. Both versions are affected.

The pages now scroll, which keeps a field at its own height at any window size,
so the minimum no longer has to grow every time a page gains a row. The tracked
list has a floor of its own so it is not the part that gives way.

Nothing else changed. If 1.2.0 looks fine to you, this is still worth taking:
the same squeeze appears as soon as you drag the window smaller.

## Фильтр масштабирования

При включённой галочке **«Вписывать изображение в размер холста по центру»**
масштабирует сам источник, а элемент сцены остаётся 1:1. Его собственный фильтр
при этом перестаёт действовать, поэтому старая игра при увеличении размывалась.

Рядом с этой галочкой появился выбор фильтра:

| Фильтр | Для чего |
| --- | --- |
| Билинейный | по умолчанию, подходит в большинстве случаев |
| Точечный | старые игры и пиксельная графика, пиксели остаются резкими |
| Бикубический | уменьшение, когда захват крупнее холста |
| Ланцош | то же самое, резче и тяжелее |

Используются штатные эффекты масштабирования OBS, те же, что для элементов
сцены, поэтому результат совпадает с тем, что сделала бы сама OBS. Ниже
половинного размера источник переключается на низкоразрешающий билинейный, где
многоотсчётные фильтры уже не помогают.

Фильтр действует, когда масштабирует сам источник. Пока блюр адресной строки
что-то закрывает, кадр рисуется его эффектом, но эта комбинация означает
браузер, которому точечная фильтрация не нужна.

## Окно настроек больше не сплющивает свои поля

Строки редактора правила могли сжиматься до нескольких пикселей. У нижней
половины окна была жёстко заданная минимальная высота, а содержимое страницы
переросло её: в 1.1.0 добавилась галочка автомасштаба, в 1.2.0 фильтр
масштабирования. Форма сжимала свои строки вместо того, чтобы окно отказалось
уменьшаться. Затронуты обе версии.

Страницы теперь прокручиваются, и это даёт гарантию, что поле сохранит свою
высоту при любом размере окна: минимум больше не надо увеличивать каждый раз,
когда на страницу добавляется строка. У списка отслеживаемых приложений
появился свой минимум, чтобы при нехватке места уступал не он.

Больше ничего не изменилось. Если в 1.2.0 у вас выглядело нормально, обновиться
всё равно стоит: то же сплющивание появляется, стоит потянуть окно меньше.
